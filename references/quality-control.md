# Quality control checklist

## Visual
- [ ] Hero subject is immediately readable.
- [ ] Composition is balanced throughout the shot.
- [ ] Lighting reveals shape and material.
- [ ] Shadows ground objects without clipping.
- [ ] Text is exact and legible at target size.
- [ ] No accidental intersections, z-fighting, or clipping.
- [ ] Motion has intentional acceleration, settle, and hold.
- [ ] No flicker, random jumps, or temporal instability.

## Technical
- [ ] Dependencies install cleanly.
- [ ] No missing local assets.
- [ ] Browser/WebGL render completes.
- [ ] Correct composition ID and dimensions.
- [ ] Output file exists and is nonzero.
- [ ] Audio and third-party assets are licensed.
- [ ] Final render settings match the brief.
