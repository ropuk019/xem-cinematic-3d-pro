# Lighting And Shadows

Use large area lights as softboxes. Key defines form, fill controls contrast, rim separates silhouette, strip lights create specular lines. Use negative fill when flat. Ground objects with a receiving floor and contact shadows. In Blender, area lights create soft penumbra; in Three.js enable shadow maps, tune bias and use contact-shadow helpers sparingly. Check acne, detached shadows and light leaks.
