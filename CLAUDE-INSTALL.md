# Claude Code install

Copy this folder into `~/.claude/skills/xem-cinematic-3d/` or the project's `.claude/skills/xem-cinematic-3d/` directory. Keep `SKILL.md`, `references/`, `blender/`, `starter/`, `scripts/` and `examples/` together. Reopen Claude Code if required, then ask it to read the skill and run a low-quality test render. The skill is workflow guidance; Blender, Node, FFmpeg and package dependencies still need to be installed on the machine.
